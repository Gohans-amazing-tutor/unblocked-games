# Unblocked Games 🎮

A sleek, Matrix-themed unblocked games website with a dark aesthetic and glowing UI elements.

## Features

- **Matrix Rain Background**: Animated falling characters with a hacker aesthetic
- **Color Scheme**: Pure black (0,0,0) with light gray accents (190,195,205)
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Multiple Games**: Snake, Tetris, Pong, Minesweeper, 2048, and Memory games
- **Smooth Animations**: Glowing effects and hover transitions

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Canvas API

## Games Included

1. **Snake** - Classic snake game
2. **Tetris** - Block stacking puzzle
3. **Pong** - Paddle ball game
4. **Minesweeper** - Logic puzzle
5. **2048** - Number sliding puzzle
6. **Memory** - Card matching game

## How to Use

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Click on any game to play
4. Press ESC to return to the main menu

## Customization

You can easily customize:
- Colors: Edit the RGB values in `style.css`
- Games: Add new game files in the `games/` directory
- Matrix Effect: Modify characters and speed in `matrix.js`
